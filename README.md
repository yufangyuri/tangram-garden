# Tangram Garden · 借景窗

Interactive three.js study for the Tangram Garden MR project (Yufang Fang / FridaXR).

- `index.html` — the whole app (three.js r149 bundled locally as `three.min.js`)
- `models/` — compressed GLB models (gltf-transform: quantize + simplify + WebP textures)

Served by GitHub Pages at `https://yufangfrida.github.io/tangram-garden/`. To test locally run `python3 -m http.server` in this folder and open http://localhost:8000 (opening the file directly will not load the models).
